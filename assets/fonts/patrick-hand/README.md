# Patrick Hand

Unmodified Patrick Hand Regular by Patrick Wagesreiter, distributed under the
SIL Open Font License 1.1 in `OFL.txt`.

Downloaded 2026-10-04 from the official Google Fonts distribution:
https://github.com/google/fonts/tree/main/ofl/patrickhand

Atlas serves the full TTF locally as `Atlas Notebook` for notebook help and notes.
It includes Latin/extended Latin characters and is precached with the app shell.
No external font service or device-installed handwriting font is required.
The regular face is deliberately used for clear, separate handwritten letters.
